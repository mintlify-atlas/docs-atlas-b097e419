The Appwrite Node.js SDK lets you interact with all Appwrite backend services from your server-side Node.js code. It provides full TypeScript support, a fluent client API, and helpers for queries, permissions, and IDs.

## Get started

<Steps>
  <Step title="Install the SDK">
    Add `node-appwrite` to your project using your preferred package manager.

    <CodeGroup>
    ```bash npm
    npm install node-appwrite
    ```
    ```bash yarn
    yarn add node-appwrite
    ```
    ```bash pnpm
    pnpm add node-appwrite
    ```
    </CodeGroup>
  </Step>
  <Step title="Initialize the client">
    Create a `Client` instance and configure it with your Appwrite endpoint, project ID, and API key.

    ```typescript
    import { Client } from 'node-appwrite';

    const client = new Client()
        .setEndpoint('https://cloud.appwrite.io/v1')
        .setProject('<YOUR_PROJECT_ID>')
        .setKey('<YOUR_API_KEY>');
    ```
  </Step>
  <Step title="Make your first request">
    Instantiate a service class and call any method. All methods return Promises.

    ```typescript
    import { Client, Users, ID } from 'node-appwrite';

    const client = new Client()
        .setEndpoint('https://cloud.appwrite.io/v1')
        .setProject('<YOUR_PROJECT_ID>')
        .setKey('<YOUR_API_KEY>');

    const users = new Users(client);

    const user = await users.create(
        ID.unique(),
        'user@example.com',
        undefined,
        'securepassword',
        'Jane Doe'
    );

    console.log(user.$id);
    ```
  </Step>
  <Step title="Handle errors">
    Wrap calls in try/catch and inspect the `AppwriteException` for details.

    ```typescript
    import { AppwriteException } from 'node-appwrite';

    try {
        const user = await users.get('<USER_ID>');
    } catch (error) {
        if (error instanceof AppwriteException) {
            console.error(error.message, error.code, error.type);
        }
    }
    ```
  </Step>
</Steps>

## Compatibility

The SDK is compatible with **Appwrite server version 1.9.x**. It works in Node.js, Deno, and any WinterCG-compatible edge runtime.

<Note>
  For browser-based applications, use the [Appwrite Web SDK](https://github.com/appwrite/sdk-for-web) instead. This SDK is designed for server-side use only.
</Note>
