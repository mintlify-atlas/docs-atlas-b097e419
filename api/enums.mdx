---
title: "Enums"
description: "TypeScript enums exported by the Appwrite Node.js SDK."
---

The SDK exports typed enums for all parameters that accept a fixed set of values. Import and use them instead of raw strings to get compile-time safety and IDE autocompletion.

```typescript
import { Runtime, ExecutionMethod, ImageFormat } from 'node-appwrite';
```

In SDK v23.0.0, the old `IndexType` enum was split into `DatabasesIndexType` (for Databases service) and `TablesDBIndexType` (for TablesDB service). Update any imports after upgrading.
