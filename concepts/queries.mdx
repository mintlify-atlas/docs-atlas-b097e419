title: "Queries"
description: "Filter, sort, and paginate results using the Query builder."
---

The `Query` class provides static factory methods that build query strings accepted by list endpoints such as `databases.listDocuments()`, `storage.listFiles()`, and `users.list()`. Pass an array of query strings as the `queries` parameter.

```typescript
import { Client, Databases, Query } from 'node-appwrite';

const client = new Client()
  .setEndpoint('https://cloud.appwrite.io/v1')
  .setProject('my-project-id')
  .setKey('my-api-key');

const databases = new Databases(client);

const result = await databases.listDocuments('my-db', 'my-collection', [
  Query.equal('status', 'active'),
  Query.orderDesc('$createdAt'),
  Query.limit(25),
]);
```

All methods return a serialized string. You can combine as many queries as needed by adding them to the array.

## Comparison filters

### Query.equal

```typescript
Query.equal(attribute: string, value: QueryTypes): string
```

Matches documents where `attribute` equals `value`. Pass an array to match any of the values (equivalent to `IN`).

```typescript
Query.equal('status', 'active')
Query.equal('rating', [4, 5])
```

### Query.notEqual

```typescript
Query.notEqual(attribute: string, value: QueryTypes): string
```

Matches documents where `attribute` does not equal `value`.

```typescript
Query.notEqual('status', 'archived')
```

### Query.lessThan

```typescript
Query.lessThan(attribute: string, value: QueryTypes): string
```

Matches documents where `attribute` is less than `value`.

```typescript
Query.lessThan('price', 100)
```

### Query.lessThanEqual

```typescript
Query.lessThanEqual(attribute: string, value: QueryTypes): string
```

Matches documents where `attribute` is less than or equal to `value`.

```typescript
Query.lessThanEqual('age', 18)
```

### Query.greaterThan

```typescript
Query.greaterThan(attribute: string, value: QueryTypes): string
```

Matches documents where `attribute` is greater than `value`.

```typescript
Query.greaterThan('score', 90)
```

### Query.greaterThanEqual

```typescript
Query.greaterThanEqual(attribute: string, value: QueryTypes): string
```

Matches documents where `attribute` is greater than or equal to `value`.

```typescript
Query.greaterThanEqual('quantity', 1)
```

### Query.between

```typescript
Query.between(attribute: string, start: string | number | bigint, end: string | number | bigint): string
```

Matches documents where `attribute` is between `start` and `end`, inclusive.

```typescript
Query.between('price', 10, 50)
Query.between('$createdAt', '2024-01-01', '2024-12-31')
```

### Query.notBetween

```typescript
Query.notBetween(attribute: string, start: string | number | bigint, end: string | number | bigint): string
```

Matches documents where `attribute` falls outside the `start`–`end` range.

```typescript
Query.notBetween('score', 0, 49)
```

### Query.isNull

```typescript
Query.isNull(attribute: string): string
```

Matches documents where `attribute` is `null`.

```typescript
Query.isNull('deletedAt')
```

### Query.isNotNull

```typescript
Query.isNotNull(attribute: string): string
```

Matches documents where `attribute` is not `null`.

```typescript
Query.isNotNull('publishedAt')
```

### Query.regex

```typescript
Query.regex(attribute: string, pattern: string): string
```

Matches documents where `attribute` matches the regular expression `pattern`.

```typescript
Query.regex('email', '^[^@]+@example\\.com$')
```

## String filters

### Query.startsWith

```typescript
Query.startsWith(attribute: string, value: string): string
```

Matches documents where `attribute` starts with `value`.

```typescript
Query.startsWith('name', 'App')
```

### Query.endsWith

```typescript
Query.endsWith(attribute: string, value: string): string
```

Matches documents where `attribute` ends with `value`.

```typescript
Query.endsWith('filename', '.png')
```

### Query.notStartsWith

```typescript
Query.notStartsWith(attribute: string, value: string): string
```

Matches documents where `attribute` does not start with `value`.

```typescript
Query.notStartsWith('slug', 'draft-')
```

### Query.notEndsWith

```typescript
Query.notEndsWith(attribute: string, value: string): string
```

Matches documents where `attribute` does not end with `value`.

```typescript
Query.notEndsWith('filename', '.tmp')
```

### Query.contains

```typescript
Query.contains(attribute: string, value: string | any[]): string
```

For string attributes, matches documents where `attribute` contains the substring `value`.

<Note>
For array attributes, use `containsAny` or `containsAll` instead.
</Note>

```typescript
Query.contains('bio', 'engineer')
```

### Query.notContains

```typescript
Query.notContains(attribute: string, value: string | any[]): string
```

Matches documents where `attribute` does not contain `value`.

```typescript
Query.notContains('tags', 'spam')
```

### Query.search

```typescript
Query.search(attribute: string, value: string): string
```

Performs full-text search on `attribute` for `value`.

<Warning>
A fulltext index must exist on the attribute before using `Query.search`.
</Warning>

```typescript
Query.search('body', 'open source database')
```

### Query.notSearch

```typescript
Query.notSearch(attribute: string, value: string): string
```

Matches documents where `attribute` does not match the full-text search for `value`. Requires a fulltext index.

```typescript
Query.notSearch('body', 'proprietary')
```

## Array filters

### Query.containsAny

```typescript
Query.containsAny(attribute: string, values: any[]): string
```

Matches documents where the array `attribute` contains at least one of the provided `values`.

```typescript
Query.containsAny('tags', ['nodejs', 'typescript'])
```

### Query.containsAll

```typescript
Query.containsAll(attribute: string, values: any[]): string
```

Matches documents where the array `attribute` contains every one of the provided `values`.

```typescript
Query.containsAll('roles', ['admin', 'editor'])
```

### Query.elemMatch

```typescript
Query.elemMatch(attribute: string, queries: string[]): string
```

Matches documents where at least one element in the array `attribute` satisfies all of the provided sub-queries.

```typescript
Query.elemMatch('comments', [
  Query.equal('approved', true),
  Query.greaterThan('likes', 10),
])
```

## Sorting

### Query.orderAsc

```typescript
Query.orderAsc(attribute: string): string
```

Sorts results by `attribute` in ascending order.

```typescript
Query.orderAsc('name')
```

### Query.orderDesc

```typescript
Query.orderDesc(attribute: string): string
```

Sorts results by `attribute` in descending order.

```typescript
Query.orderDesc('$createdAt')
```

### Query.orderRandom

```typescript
Query.orderRandom(): string
```

Sorts results in a random order.

```typescript
Query.orderRandom()
```

## Pagination

<Tip>
Cursor-based pagination (`cursorAfter` / `cursorBefore`) is more efficient than offset pagination for large datasets.
</Tip>

### Query.limit

```typescript
Query.limit(limit: number): string
```

Limits the number of results returned.

```typescript
Query.limit(25)
```

### Query.offset

```typescript
Query.offset(offset: number): string
```

Skips the first `offset` results.

```typescript
Query.offset(50)  // page 3 with limit 25
```

### Query.cursorAfter

```typescript
Query.cursorAfter(documentId: string): string
```

Returns results after the document with the given ID (exclusive). Use the `$id` of the last document from the previous page.

```typescript
Query.cursorAfter('doc_abc123')
```

### Query.cursorBefore

```typescript
Query.cursorBefore(documentId: string): string
```

Returns results before the document with the given ID (exclusive). Use the `$id` of the first document from the current page to paginate backwards.

```typescript
Query.cursorBefore('doc_abc123')
```

## Attribute selection

### Query.select

```typescript
Query.select(attributes: string[]): string
```

Returns only the specified attributes in each document. Always include `$id` if you need the document ID.

```typescript
Query.select(['$id', 'name', 'email'])
```

## Logical operators

### Query.or

```typescript
Query.or(queries: string[]): string
```

Matches documents that satisfy any one of the provided queries.

```typescript
Query.or([
  Query.equal('status', 'active'),
  Query.equal('status', 'pending'),
])
```

### Query.and

```typescript
Query.and(queries: string[]): string
```

Matches documents that satisfy all of the provided queries. Useful for grouping conditions when combining with `Query.or`.

```typescript
Query.and([
  Query.greaterThan('price', 10),
  Query.lessThan('price', 100),
])
```

## Date helpers

These are convenience wrappers around the comparison filters that target the built-in `$createdAt` and `$updatedAt` attributes. Dates must be ISO 8601 strings.

### Creation date

```typescript
Query.createdBefore(value: string): string   // lessThan('$createdAt', value)
Query.createdAfter(value: string): string    // greaterThan('$createdAt', value)
Query.createdBetween(start: string, end: string): string  // between('$createdAt', start, end)
```

```typescript
Query.createdAfter('2024-01-01T00:00:00.000Z')
Query.createdBetween('2024-06-01T00:00:00.000Z', '2024-06-30T23:59:59.999Z')
```

### Update date

```typescript
Query.updatedBefore(value: string): string
Query.updatedAfter(value: string): string
Query.updatedBetween(start: string, end: string): string
```

```typescript
Query.updatedAfter('2024-01-01T00:00:00.000Z')
```

## Geospatial filters

Geospatial queries operate on attributes that store GeoJSON geometry. The `values` parameter accepts a GeoJSON geometry object (as an array/object). `meters` defaults to `true`; pass `false` to use kilometers.

### Distance filters

```typescript
Query.distanceEqual(attribute: string, values: any[], distance: number, meters?: boolean): string
Query.distanceNotEqual(attribute: string, values: any[], distance: number, meters?: boolean): string
Query.distanceGreaterThan(attribute: string, values: any[], distance: number, meters?: boolean): string
Query.distanceLessThan(attribute: string, values: any[], distance: number, meters?: boolean): string
```

```typescript
// Documents within 500 metres of a point
Query.distanceLessThan('location', [{ type: 'Point', coordinates: [-0.1276, 51.5074] }], 500)

// Documents more than 10 km away
Query.distanceGreaterThan('location', [{ type: 'Point', coordinates: [-0.1276, 51.5074] }], 10000, false)
```

### Geometry relationship filters

```typescript
Query.intersects(attribute: string, values: any[]): string
Query.notIntersects(attribute: string, values: any[]): string
Query.crosses(attribute: string, values: any[]): string
Query.notCrosses(attribute: string, values: any[]): string
Query.overlaps(attribute: string, values: any[]): string
Query.notOverlaps(attribute: string, values: any[]): string
Query.touches(attribute: string, values: any[]): string
Query.notTouches(attribute: string, values: any[]): string
```

```typescript
const boundingBox = {
  type: 'Polygon',
  coordinates: [[[-0.2, 51.4], [0.0, 51.4], [0.0, 51.6], [-0.2, 51.6], [-0.2, 51.4]]],
};

Query.intersects('region', [boundingBox])
```

## Combining queries

Pass multiple queries as an array. All top-level queries are implicitly ANDed together. Use `Query.or` to express OR conditions.

```typescript
const documents = await databases.listDocuments('my-db', 'products', [
  Query.equal('inStock', true),
  Query.or([
    Query.lessThan('price', 20),
    Query.greaterThan('rating', 4),
  ]),
  Query.select(['$id', 'name', 'price', 'rating']),
  Query.orderDesc('rating'),
  Query.limit(10),
]);
```
