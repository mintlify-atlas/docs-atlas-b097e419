## Prerequisites

- Node.js 18 or later
- An [Appwrite](https://cloud.appwrite.io) project (Cloud or self-hosted)
- An API key with the scopes needed for your operations

## Install the SDK

<CodeGroup>

```bash npm
npm install node-appwrite
```

```bash yarn
yarn add node-appwrite
```

```bash pnpm
pnpm add node-appwrite
```

</CodeGroup>

## Set up the client

Import `Client` and configure it with your project endpoint, project ID, and API key. All three are required for server-side operations.

<CodeGroup>

```typescript TypeScript
import { Client } from 'node-appwrite';

const client = new Client()
    .setEndpoint('https://cloud.appwrite.io/v1') // Default Appwrite Cloud endpoint
    .setProject('<YOUR_PROJECT_ID>')             // Your project ID
    .setKey('<YOUR_API_KEY>');                   // Your secret API key
```

```javascript JavaScript
const { Client } = require('node-appwrite');

const client = new Client()
    .setEndpoint('https://cloud.appwrite.io/v1') // Default Appwrite Cloud endpoint
    .setProject('<YOUR_PROJECT_ID>')             // Your project ID
    .setKey('<YOUR_API_KEY>');                   // Your secret API key
```

</CodeGroup>

<Tip>
  Find your project ID in the Appwrite Console under **Settings → Overview**. Create an API key under **Settings → API Keys**.
</Tip>

## Make your first request

Use the `Users` service to list existing users in your project.

<CodeGroup>

```typescript TypeScript
import { Client, Users } from 'node-appwrite';

const client = new Client()
    .setEndpoint('https://cloud.appwrite.io/v1')
    .setProject('<YOUR_PROJECT_ID>')
    .setKey('<YOUR_API_KEY>');

const users = new Users(client);

const response = await users.list();
console.log(response.users);
```

```javascript JavaScript
const { Client, Users } = require('node-appwrite');

const client = new Client()
    .setEndpoint('https://cloud.appwrite.io/v1')
    .setProject('<YOUR_PROJECT_ID>')
    .setKey('<YOUR_API_KEY>');

const users = new Users(client);

const response = await users.list();
console.log(response.users);
```

</CodeGroup>

## Create a user with ID.unique()

The `ID.unique()` helper generates a unique ID for a new resource. You can also supply your own ID with `ID.custom('my-id')`.

<CodeGroup>

```typescript TypeScript
import { Client, Users, ID, AppwriteException } from 'node-appwrite';

const client = new Client()
    .setEndpoint('https://cloud.appwrite.io/v1')
    .setProject('<YOUR_PROJECT_ID>')
    .setKey('<YOUR_API_KEY>');

const users = new Users(client);

try {
    const user = await users.create(
        ID.unique(),              // Let Appwrite generate a unique ID
        'jane@example.com',       // Email
        '+15550001234',           // Phone (optional)
        'supersecretpassword',    // Password (optional)
        'Jane Doe',               // Name (optional)
    );
    console.log('Created user:', user.$id);
} catch (error) {
    if (error instanceof AppwriteException) {
        console.error(`Appwrite error ${error.code}: ${error.message}`);
    } else {
        throw error;
    }
}
```

### ID helpers

| Method | Description |
|---|---|
| `ID.unique()` | Generates a unique hex ID from a timestamp plus random padding |
| `ID.custom('my-id')` | Uses the string you provide as the resource ID |

## Error handling

All SDK methods throw `AppwriteException` on failure. It exposes three properties:

| Property | Type | Description |
|---|---|---|
| `message` | `string` | Human-readable error description |
| `code` | `number` | HTTP status code (e.g. `404`, `401`) |
| `type` | `string` | Appwrite error type string |
| `response` | `string` | Raw response body |

```typescript
import { AppwriteException } from 'node-appwrite';

try {
    await users.get('nonexistent-id');
} catch (error) {
    if (error instanceof AppwriteException) {
        // error.code  → 404
        // error.type  → "user_not_found"
        // error.message → "User with the requested ID could not be found."
        console.error(error.message);
    }
}
```
